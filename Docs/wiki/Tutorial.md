## Playtest walkthrough — a new Nuian character in Solzreed

The fork's M1 golden route ([Golden Route — Solzreed](Golden-Route-Solzreed))
is the curated opening progression. A quick playtest loop:

1. **Create a Nuian character** — spawn in Solzreed (zones 9/124/125).
2. **Level 1–3** — notice-board kills (250, 251, 329, 330) and village
   errands (2239, 252, 324, 325, 2531, 2532).
3. **Level 3–6** — the main village chain 254 → 255 → 256 → 257 → 259
   (plus the 260 → 261 fan) carries the story.
4. **The mount chain** — shepherd/pickaxe arc (265 → 266 → 354) unlocks
   4292 → 4294 → 4295, ending with the first mount (item 18649).
5. **Levels 4–10 (parallel)** — the Bloody Hand investigation
   2255 → 2256 → … → 2266.

**Known issues to expect:** see the blockers section of the golden-route page.
The one real defect class is timed-quest persistence (350, 4292 — a restart
mid-quest is the risk); the rest are harness/manifest artifacts, not live
gameplay blockers.

The full per-quest route table, gates, and intentionally excluded quests live
on [Golden Route — Solzreed](Golden-Route-Solzreed); per-quest harness
verdicts are in `scorecard-explorations/runnability.md`.
